# 取证与更新规则

## 1. 证据优先级

1. 正式出版、官方可读的漫画分镜与日文原文。若章节曾被重画，注明版本。
2. 同一章节的可靠授权翻译；涉及关键术语时尽量对照日文（如「不老手術」）。
3. 尾田在SBS、官方访谈和出版物中的明确说明。
4. 人物在漫画中的台词。注意人物可能误解事实、撒谎或只有部分信息。
5. 非官方剧情摘要、新闻、读者逐话分析，用来定位章节，不作为定案来源。
6. 提前泄露情报：隔离标注 X，正式刊出前不能用于证实。

## 2. 防止事后诸葛亮

预测创建时保存：创建日期、当时已正式刊出的最大话数、证据、预测结果、可证伪条件。之后只能追加验证，不可默默替换原预测。

## 3. 不得混同的概念

- “不老手术”≠已经证实“生命力无限”。
- “伊姆能授予契约能力”≠已经证实“他能制造可食用、死后重生的恶魔果实”。
- “动物系拥有意志”≠伊姆果实必属动物系，更不等于伊姆已遭夺舍。
- “伊姆暂时被击伤”≠“伊姆的不死被终结”。
- “某角色与D有关”≠“道德上必然善良”。
- “鱼人岛预言被毁”≠“红土大陆必然被路飞打碎”。
- “罗杰说想在同一时代相遇”指乔伊波伊，不是把路飞直接说成其台词中的对象。
- “伊姆能使用旧王兵器”≠其夺舍了全部旧王；讨论中提到的19把武器与20王誓约，需要从原文确认细节。

## 4. 内容边界

项目公开时只含本次聊天相关的作品讨论与资料，不包括其他私人仓库、身份识别信息、内部工作内容及账户密钥。对话中的原创推测均注明为用户／助手提出，不以“官方”名义传播。

## 5. 建议 GitHub 管理规则

- `main` 保留对话归档和当前研究结论。
- 每次新话核查以独立提交记录变化。
- 重大假说分配 H 编号，并保留至少一个反例。
- 有争议译法在独立条目保留原文、译法及出处。
- 不上传完整未经许可的漫画扫描图、翻译成套文本或转载视频文件。
